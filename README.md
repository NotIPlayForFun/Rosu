# Rosu
Automatic temporary osu! replay saving

## Setup

Needs Windows, Python 3.11+ and [tosu](https://github.com/tosuapp/tosu) running alongside osu! stable.

```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Running

From the repo folder:

```
python -m rosu
```
